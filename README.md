# 장마감 시황 브리핑

공개 시세와 뉴스 제목을 먼저 수집해 브리핑을 표시합니다. 기본 조회, 종목검색, 종목 시세 조회에는 Gemini 키나 AI 토큰이 필요하지 않습니다.

- 시세: Yahoo Finance 공개 chart 엔드포인트. 선택한 공급자 현지 날짜의 일별 봉을 사용하며 이전 유효 거래일 종가와 등락률을 계산합니다. 다른 날짜를 대신 표시하지 않습니다.
- 뉴스: Google News 공개 RSS. 현지 게시일과 시장 관련 제목을 필터링하며, 제목·매체·링크만 표시합니다. 기사 본문을 수집하거나 읽은 것으로 표현하지 않습니다.
- AI: 리포트를 표시한 뒤 **AI 해석 추가 (선택)** 버튼으로만 호출합니다. 서버에서 수집한 숫자와 최대 3개 제목만 전달하고 요약·해석 두 필드만 받습니다. Google Search 도구, 기사 본문, 대화 기록을 전달하지 않습니다.
- 429, 타임아웃, 응답 형식 오류에도 기본 리포트와 시세·뉴스를 유지합니다. 실패 요청을 자동 재시도하지 않습니다.

## Vercel 환경 변수

| 이름 | 기본값 / 용도 |
| --- | --- |
| `GEMINI_API_KEY` | 선택. 없으면 무료 데이터 조회만 작동합니다. |
| `GEMINI_SUMMARY_MODEL` | `gemini-2.5-flash-lite`. AI 해석 전용 모델입니다. 기존 `GEMINI_MODEL`은 사용하지 않습니다. |
| `GEMINI_SUMMARY_ENABLED` | `false`로 지정하면 AI 호출을 완전히 끕니다. |

2.5 Flash/Flash-Lite에서는 추론 예산을 0으로 지정하며, AI 출력 상한은 1,024토큰입니다. 실제 사용량은 응답의 `usage`에 표시합니다. 최대 토큰 수는 상한이며 고정 소비량이 아닙니다. 무료 사용 가능량은 Google 프로젝트·모델별 한도에 따르며 토큰을 줄여도 요청/일일 한도를 없앨 수는 없습니다.

## 캐시 및 제한

리포트는 서버 인스턴스에서 5분, 개별 시세와 뉴스는 30분 캐시합니다. 종목검색은 6시간, 종목 상세는 5분 캐시합니다. 동일 요청을 합쳐 처리하고 브라우저 세션에서도 기본 리포트를 5분 재사용합니다. AI 성공 해석은 동일 입력에 대해 최대 6시간 재사용하며 오류는 잠시 저장합니다. 429 후에는 `Retry-After` 또는 기본 15분 동안 추가 AI 요청을 억제합니다.

서버 캐시와 AI 쿨다운은 인스턴스별이며 여러 인스턴스에 걸친 전역 한도는 아닙니다. 공개 엔드포인트는 정식 유료 시세 서비스와 같은 가용성/이용 조건을 보장하지 않습니다. 공급자가 최신 일별 봉이나 과거 기사를 제공하지 않으면 `확인 불가`와 주의 문구를 표시합니다. 특히 환율·원자재는 주식시장과 마감시각이 다릅니다. 기업 실적, 특징주, 주도 섹터는 임의로 생성하지 않습니다.

각 공개 요청은 7~8초, 선택형 AI 해석은 12초 이내로 제한합니다. 기존 Vercel Edge 런타임을 유지합니다. 추가 패키지 설치는 필요하지 않습니다.

## 검증

```sh
node --test tests/market-report.test.mjs
```

테스트는 가짜 공급자 응답으로 무료 조회, 선택형 AI 호출, 429/시간초과 시 기본 결과 유지, 캐시, 날짜/타임존, 뉴스 필터, UI 렌더링을 확인합니다. 실제 Google 프로젝트의 무료 한도나 AI 응답 품질을 대신 검증하지는 않습니다.
