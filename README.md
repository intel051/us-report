# 클로징 노트

그날 장을 돌아보는 시황 브리핑입니다. 시장·현지 거래일을 선택하면 공개 시세와 뉴스 속 특징주를 먼저 보여주고, 기본으로 켜진 **마감시황 함께 작성** 옵션에 따라 Gemini가 하루의 회고를 작성합니다. 자료만 보고 싶으면 옵션을 끌 수 있습니다.

## 데이터와 특징주

- Yahoo 공개 일별 시세: 지수·환율·금·WTI, 미국 11개 섹터 ETF, VIX·미국 10년물. 선택일과 일치하는 공급자 현지 일별 봉만 사용합니다. 최근 유효 거래일 종가 흐름도 함께 표시합니다.
- Google News RSS: 날짜별 마감 기사와 특징주 기사의 제목·매체·원문 링크. 기사 본문을 읽은 것으로 표현하지 않습니다.
- 특징주: `lib/stock-universe.js`에 정의된 미국·한국·일본 기업 별칭과 기사 제목을 연결합니다. 기사 언급 수로 최대 6개를 고르고 해당 날짜의 실제 종가 등락을 붙입니다. 전체 시장 상승률 순위가 아니며, 지원 목록 밖의 기업은 자동 인식하지 않습니다. 확인하지 못한 시세는 다른 날짜로 대체하지 않습니다.
- 종목 카드와 직접 종목검색 모두 선택한 날짜의 시세를 봅니다. 기업 개요·당일 주목 이유·당시 공개된 최근 실적·관찰할 점을 표시하고, Gemini가 별도 요청으로 짧은 기업 해설을 덧붙입니다.
- 섹터 ETF 수익률은 미국 시장의 대용지표입니다. 금리 변화는 bp, 주가/ETF 등락은 %로 구분합니다. 환율·상품의 현재 일별 봉이 진행 중이면 확정 종가로 표시하지 않습니다.

## 마감시황 작성

자료를 표시한 다음 별도 요청으로 Gemini가 **제목·핵심 요약·세 개의 회고 문단·다음 관찰점**을 작성합니다. 숫자, 업종/특징주와 최대 6개 기사 제목만 전달합니다. 검색 도구·기사 본문·대화 기록은 전송하지 않으며 일별 종가로 장중 경로를 만들지 않도록 지시합니다. 응답을 검증한 뒤 문단을 표시합니다.

429·시간초과·JSON 오류·키 누락에도 수집한 시세와 뉴스를 유지합니다. 실패 요청은 자동 반복하지 않습니다. 동일 자료로 작성된 시황은 재사용합니다.

| 환경 변수 | 용도 |
| --- | --- |
| `GEMINI_API_KEY` | 시황 작성용 키. 없으면 수집 자료만 표시합니다. |
| `GEMINI_SUMMARY_MODEL` | 기본 `gemini-3.5-flash-lite`. 기존 `GEMINI_MODEL`과 별개입니다. 이전 `gemini-2.5-flash-lite` 설정도 신규 사용자 접근 제한을 피하도록 3.5 Flash-Lite로 이전합니다. |
| `GEMINI_SUMMARY_ENABLED` | `false`면 모든 AI 작성을 끕니다. |

기본 3.5 Flash-Lite는 minimal 추론 수준과 출력 상한 2,048토큰을 사용합니다. 이 값은 고정 소비량이 아닌 잘림 방지 상한입니다. 무료 사용량은 프로젝트·모델별 한도에 따릅니다.

## 캐시·실행 시간

기본 리포트/종목 상세는 서버 인스턴스에서 5분, 개별 일별 시세/RSS는 30분, 종목검색은 6시간 캐시합니다. 브라우저 세션도 기본 자료를 5분 재사용합니다. AI 시황은 동일 입력에 최대 6시간 재사용하며 요청을 합쳐 처리합니다. 오류는 잠시 저장하고 429 이후에는 Retry-After 또는 기본 15분 동안 추가 AI 호출을 멈춥니다. 캐시와 쿨다운은 인스턴스별이며 전역 한도가 아닙니다.

기본 자료는 병렬 수집하고 뉴스 확인 뒤 특징주 시세를 한 번 더 병렬 수집합니다. 시황 작성은 보통 이미 수집한 자료를 재사용하는 별도 요청입니다. 콜드 요청도 Edge 첫 응답 제한을 고려해 AI 대기시간을 남은 예산에 맞춥니다. 추가 패키지 설치는 필요하지 않습니다.

공개 엔드포인트는 가용성·과거 검색 범위를 보장하지 않습니다. 한국·일본 시장 최신 일별 봉 제공이 지연될 수 있습니다. 지수가 없더라도 당일 기사 자료가 있으면 누락을 명시한 회고를 작성할 수 있습니다. 모든 자료가 없으면 AI 호출을 생략합니다.

## 검증

```sh
node --test tests/market-report.test.mjs
```

테스트는 날짜/타임존, 특징주 매칭·등락·원문, 선택일 종목 상세, 업종/금리 단위, 시황 스키마, 429/시간초과 시 자료 유지, 자동 작성 순서, 캐시와 DOM 렌더링을 확인합니다. 실제 Gemini 프로젝트의 무료 한도나 응답 품질은 별도 확인이 필요합니다. 모션은 `prefers-reduced-motion`을 지원합니다.

## Gemini 오류 진단과 요청 분리

Google HTTP 400/401/403/404/429, 출력 잘림, JSON/스키마 오류, 연결 실패와 시간초과를 구분합니다. Vercel 로그에서 `event=gemini_report`와 화면의 진단 ID를 찾으면 같은 호출을 확인할 수 있습니다. API 키, 프롬프트, 보고서 본문은 기록하지 않습니다. 오류의 키/프로젝트 식별자는 가립니다. 화면에는 수집 자료를 유지하면서 모델·HTTP 상태·실패 사유를 표시합니다.

기본 자료 응답에는 공개 자료 요약을 서버의 HMAC 서명으로 확인할 수 있는 30분 컨텍스트가 포함됩니다. 프런트의 `write_report` 요청은 이 컨텍스트를 전달합니다. 다른 Edge 인스턴스로 가더라도 시세·뉴스를 다시 수집하지 않고 서명을 검증해 같은 자료로 작성하므로 AI 응답을 최대 20초 기다릴 수 있습니다. 키는 서명 검증에만 서버에서 사용하며 응답에 포함하지 않습니다. 만료/변조/키 교체로 검증에 실패하면 자료를 다시 불러오도록 안내하고 AI를 호출하지 않습니다. 기존 `report` + `useAI:true` 요청도 계속 지원합니다.

## 종목 상세와 기업 해설

`lib/company-data.js`에서 무료 SEC companyfacts·submissions 및 당시 10-K Business 발췌와 선택일 Google News RSS를 수집합니다. SEC는 키 없이 서버에서 조회하며 `SEC_USER_AGENT`로 운영자 연락처가 포함된 User-Agent를 지정할 수 있습니다. 기본값은 서비스와 GitHub 문의 주소입니다. 공급자 실패·크기/시간 제한 시 누락을 명시하고 확인된 시세를 유지합니다.

실적은 선택일까지 공시된 미국 GAAP 매출(USD)과 희석 EPS(USD/주)만 지원합니다. 분기 약 70~110일, 연간 약 330~390일의 같은 시작·종료일 자료를 맞추며 YTD와 분기를 섞지 않습니다. 전년 동기 대비 증감률은 동일 길이의 비교 기간과 양수 분모가 있을 때만 계산합니다. 음수 EPS·비교 자료 누락은 증감률을 생략합니다. 미래 공시/재작성 자료는 제외합니다. SEC 공시일과 실제 실적 발표일은 다를 수 있으며 같은 날짜 내 장전/장후 공개 시각은 구분하지 않습니다. XBRL 태그·통화·기업별 공시 차이로 수치가 없을 수 있습니다. 한국·일본/외국기업의 IFRS 실적은 현재 자동 수집 대상이 아닙니다.

사업 설명은 선택일까지 제출된 최근 목록 내 10-K의 Business 발췌만 사용합니다. 과거 문서 목록 전체를 추가 순회하지 않으므로 오래된 날짜나 원문 접근 제한 시 기업 개요를 확보하지 못할 수 있습니다. 뉴스는 해당 현지 날짜에 발행되고 기업명/티커가 포함된 제목 최대 3개이며 기사 본문은 수집하지 않습니다. 시장 예상치·가이던스는 검증된 별도 자료가 없어 표시하지 않습니다.

기업 해설은 서버 서명된 `kind=stock` 자료만 `write_stock`에 전달합니다. 보고서 서명과 용도를 구분하며 숫자 카드는 AI 결과로 덮어쓰지 않습니다. 동일 종목·날짜·자료·모델 입력은 6시간 재사용하고 동시 요청을 합칩니다. 기업 해설도 기존 모델 설정·429 쿨다운·오류 캐시를 공유합니다. 공개 공시 원본 캐시는 6시간, 기업별 수집 결과는 30분입니다. 데이터 수집 후 AI 호출을 분리하여 각 단계의 시간 제한을 둡니다.

### Vercel에서 SEC 연결이 제한되는 경우

공개 SEC 엔드포인트가 배포 서버에서 응답하지 않으면 `lib/sec-snapshot.js`의 주요 미국 종목 공시 보조 자료를 사용합니다. 각 자료의 원래 공시일로 다시 필터링하므로 선택일 이후 실적/사업 설명은 사용하지 않습니다. 화면에는 보조 자료 수집일과 이후 공시가 누락될 수 있다는 점을 표시합니다. 보조 자료는 자동 갱신되지 않으며, 갱신은 `python scripts/update-sec-snapshot.py` 실행 후 결과를 커밋/배포합니다. 이 스크립트는 미국 특징주 목록의 SEC 자료를 제한된 동시 요청으로 수집하고 일시 실패한 기업의 기존 자료는 유지합니다. 실시간 SEC 조회에 성공하면 그 결과를 우선합니다. IFRS 공시나 지원하지 않는 XBRL 태그는 추정하지 않습니다.
